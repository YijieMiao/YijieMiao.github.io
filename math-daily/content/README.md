# 开场句库

`quotes.json` 共 100 条，原文与译意分开存储。中文分为 `text` 与 `continuation`，外文在 `translation` 中保存本站编写的中文译意，不冒充某一出版译本。保留作品名；小说、戏剧和电影中的句子是作品摘句或人物台词，不视为作者本人立场。

参考原文：

- 英文小说、戏剧：Project Gutenberg，对应条目的 `source_url` 指向原作。莎士比亚、《简·爱》、《呼啸山庄》、狄更斯、《小妇人》、《绿山墙的安妮》、《爱丽丝梦游仙境》和《瓦尔登湖》的摘句已与该站原文比对，忽略标点和排印差异；修正了常见流传版本的改写。
- 夏目漱石《草枕》：https://www.aozora.gr.jp/cards/000148/files/776_14941.html 。日文俳句使用通行文字形态，空格用于分节，并非原作标点。
- 电影短句：American Film Institute, https://www.afi.com/afis-100-years-100-movie-quotes/ 。
- 其他诗文按作者和篇目标注，篇名或首句作为作品标识。

选句库不调用 AI，不进行运行时翻译。`quotes.js` 控制展示与轮换，独立于论文抓取及个人收藏。
